- **Вопрос владельцу:** где версия парсера, которой построены сводные очного выпуска 2026? Если её нет — правила: з.е. = сумма часов всех семестров / 36 с округлением; итоговая оценка — оценка последнего семестра (экзамен важнее зачёта?); курсовая — отдельной строкой.
