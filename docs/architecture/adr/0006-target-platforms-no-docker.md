# ADR-0006. Целевые платформы и отказ от Docker как требования

- **Статус:** предложено
- **Дата:** 25.09.2026

## Контекст

В вузах одновременно работают компьютеры с Windows 7/8.1 (в том числе 32-битными), Windows 10/11 и российскими Linux (Astra Linux, РЕД ОС, Альт). На старых Windows и 32-битных системах Docker не работает; в закрытых контурах Astra Linux установка стороннего ПО ограничена, а при замкнутой программной среде запускаются только подписанные исполняемые файлы.

## Решение

Обязательные платформы:

| Платформа | Архитектура | Поставка |
|---|---|---|
| Windows 7, 8.1 | x86, x64 | переносимый архив или установщик |
| Windows 10, 11 | x64 | переносимый архив или установщик |
| Astra Linux (от 1.7) | x64 | пакет `.deb`, служба systemd |
| Альт | x64 | пакет `.rpm`, служба systemd |
| РЕД ОС | x64 | пакет `.rpm`, служба systemd |

- Docker не требуется. Образ Docker может появиться как дополнительный способ установки на сервер, но не как основной.
- Никаких предустановленных рантаймов: всё нужное входит в поставку.
- Минимальные браузеры для интерфейса: Chrome 109, Firefox ESR 115.

## Последствия

- Выбор стека ограничен инструментами, которые собирают исполняемые файлы для Windows 7 x86 и Linux со старой glibc (см. раздел 13 [README](../README.md)).
- Для Astra Linux нужна процедура подписи исполняемых файлов.
- Нужны виртуальные машины Windows 7 (32 бит) и Astra Linux для проверки каждой версии.

## Отвергнутые варианты

- **Только современные ОС:** отсекает значительную часть рабочих мест в вузах.
- **Docker как основной способ поставки:** недоступен на части целевых платформ.
