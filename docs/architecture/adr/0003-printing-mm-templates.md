# ADR-0003. Печать: PDF из шаблонов в миллиметрах, калибровка, импорт `.fr3`

- **Статус:** предложено
- **Дата:** 25.09.2026

## Контекст

Дипломы печатаются на защищённых бланках типографий; актуальный поставщик — «Полиграфзащита» (Ижевск). КиберДиплом использует шаблоны FastReport 4 (`.fr3`: gzip + XML) с координатами полей в пикселях при 96 dpi. В архиве вуза есть эталонные шаблоны Полиграфзащиты для титулов и приложений бакалавра, специалиста, магистра и аспирантуры: титул — A4 альбомная (297×210 мм), приложение — 4 страницы A3 альбомные (420×297 мм). Принтеры сдвигают печать по-разному, браузеры могут масштабировать PDF.

## Решение

- Собственный формат шаблона: страницы (формат, ориентация) и поля в миллиметрах — координаты, шрифт, размер, выравнивание, перенос, ужатие, перетекание таблицы дисциплин между страницами приложения.
- Выходной формат — PDF в масштабе 1:1 со встроенными шрифтами; фон бланка используется только в предпросмотре.
- Калибровка на каждый принтер: смещения dx и dy (мм), подобранные по тестовому листу.
- Импорт шаблонов `.fr3` с переводом координат (1 мм = 3,7795 пикселя) и сопоставлением полей FastReport с моделью данных (таблица в разделе 7 [README](../README.md)).
- Первые шаблоны — Полиграфзащита; другие типографии добавляются тем же импортом.
- Шрифт по умолчанию — PT Astra Serif (открытая лицензия, метрически совместим с Times New Roman); если в системе есть Times New Roman, его можно выбрать.
- Шаблоны типографий не включаются в открытый репозиторий, пока не проверены их лицензии; каждый вуз импортирует свои.
- Серия и номер бланка выбираются из учёта бланков строгой отчётности; испорченный бланк списывается.

## Последствия

- Печать одинакова в обоих режимах и на всех ОС: PDF печатается из браузера или системного просмотрщика.
- Пользователю нужна инструкция «печатать в масштабе 100%» и проверка калибровки при смене принтера.
- Нужен собственный движок раскладки текста (перенос, ужатие, перетекание таблиц) — это самая сложная часть MVP.

## Отвергнутые варианты

- **Печать HTML из браузера:** точность позиционирования зависит от браузера и его настроек.
- **Встроить FastReport:** проприетарный компонент под Windows.
- **Прямая печать в драйвер принтера:** разная реализация под каждую ОС; не работает в серверном режиме.
