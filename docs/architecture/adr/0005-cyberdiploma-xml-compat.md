# ADR-0005. Совместимость с КиберДипломом только через XML 3.5.1

- **Статус:** предложено
- **Дата:** 25.09.2026

## Контекст

На переходный период вуз продолжает печатать в КиберДипломе. Его база и карточки (`.davf`, `.cdc`, `.cdt`) — зашифрованный контейнер с общей сигнатурой; формат закрыт. Открытый путь обмена — XML «ФайлОбменаКиберДиплом» версии 3.5.1, который КиберДиплом импортирует и который уже генерирует этот репозиторий.

## Решение

- Экспорт в XML 3.5.1 — часть MVP: студенты, ГИА, дисциплины, практики, курсовые, факультативы, объёмы, дополнительные сведения.
- Импорт XML 3.5.1 — через промежуточную зону (ADR-0004), для переноса уже подготовленных данных.
- Файлы `.davf`, `.cdc`, `.cdt` не разбираем и не расшифровываем.
- Данные документа (регистрационный номер, дата выдачи, бланк) и организации в XML 3.5.1 отсутствуют — при работе через КиберДиплом их по-прежнему вводят в нём.

## Последствия

- Нет юридических рисков, связанных с обходом защиты чужого формата.
- История выдачи из КиберДиплома в новую систему автоматически не переносится.
- Экспорт XML проверяется тестами на соответствие тегам, реально принимаемым КиберДипломом (файлы 2025–2026 годов).

## Отвергнутые варианты

- **Разбор `.davf`:** закрытый зашифрованный формат, юридический риск, хрупкость при обновлениях КиберДиплома.
- **Автоматизация интерфейса КиберДиплома (AutoIt, как в 2025 году):** хрупко, зависит от версии программы и разрешения экрана.
