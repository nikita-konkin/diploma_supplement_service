# ADR-0007. Технологический стек

Статус: **принято** владельцем 25.09.2026: Java 11 LTS. Прототип проверяет платформенные риски (Windows 7 x86, Astra с ЗПС); если они не подтвердятся, решение пересматривается в пользу запасного варианта.

## Контекст

Обязательные требования — раздел 13 [README](../README.md) и ADR [0001](0001-modular-monolith-local-web.md), [0002](0002-storage-sqlite-postgresql.md), [0003](0003-printing-mm-templates.md), [0006](0006-target-platforms-no-docker.md). Большинство кандидатов отсеивают три из них:

1. **Windows 7/8.1, в том числе 32-битные.** Нужен инструмент, который ещё получает обновления безопасности и собирает под x86.
2. **Astra Linux 1.7** (glibc 2.28), РЕД ОС, Альт; в Astra возможен режим замкнутой программной среды (ЗПС), где запускаются только подписанные исполняемые файлы.
3. **Без установки рантайма**, при этом чтение `.xls` и `.xlsx` и PDF с точным положением полей в миллиметрах.

## Сравнение

| | Java 11 LTS, рантайм в поставке | Go (форк для Windows 7) | Python 3.8 + PyInstaller | Free Pascal / Lazarus |
|---|---|---|---|---|
| Windows 7 x86 | Liberica JDK 11 официально поддерживает Windows 7 32/64 бит, обновления выходят | официальный Go — только 1.20 (без обновлений с 2024); форк `go-legacy-win7` доведён до 1.25, есть 386, поддерживает сообщество | Python 3.8 — последний с Windows 7, поддержка закончилась в октябре 2024 | отлично |
| Astra, РЕД ОС, Альт | Axiom JDK Certified: реестр российского ПО № 17783, сертификат ФСТЭК № 4531, x86/x86_64, Astra SE, Альт, РЕД ОС; OpenJDK есть и в репозиториях дистрибутивов | статический файл без зависимости от glibc — лучший вариант | нужна сборка на старой glibc | хорошо |
| Поставка | архив с урезанным рантаймом (jlink), 50–70 МБ, запускатель; `.deb`/`.rpm` | один файл 15–30 МБ | 100+ МБ с pandas; антивирусы часто ругаются на однофайловые сборки | один небольшой файл |
| `.xlsx` и `.xls` | Apache POI — лучшая библиотека для обоих | excelize для `.xlsx` хорош, для `.xls` библиотеки слабые | openpyxl + xlrd | fpspreadsheet |
| PDF в мм, кириллица, шаблоны | OpenPDF / PDFBox; JasperReports — визуальный конструктор шаблонов, аналог FastReport | go-pdf/fpdf, gopdf; конструктора нет | reportlab | есть, но узкое сообщество |
| SQLite и PostgreSQL | JDBC: sqlite-jdbc (нативные библиотеки внутри, в том числе Windows x86), PostgreSQL JDBC, миграции Flyway 9 | pgx; SQLite без cgo (modernc) — поддержку windows/386 проверять | встроенный sqlite3, psycopg2 | есть |
| Веб-интерфейс | встроенный Jetty/Javalin или Takes, серверный HTML + htmx | стандартная библиотека + htmx | FastAPI/Flask + htmx | не основная область |
| Команда и код | шлюз уже на Java; правила из Python переносятся по тестам | новый для команды язык | прямое переиспользование кода | нет опыта |

Отклонены сразу: современный .NET не работает на Windows 7, а .NET Framework — только Windows; Node.js и Electron для Windows 7 давно без обновлений; у Rust Windows 7 осталась только в целях третьего уровня.

## Решение

**Java 11 LTS** (байт-код 11) с рантаймом в поставке:

- Windows 7/8.1 x86 и x64 — Liberica JDK 11 (или Axiom JDK), урезанный jlink;
- Windows 10/11 — тот же рантайм 11 или 17 x64;
- Astra, Альт, РЕД ОС — пакет с зависимостью от OpenJDK из репозитория дистрибутива или с Axiom JDK Certified; сам код в `.jar`, который ЗПС не проверяет как исполняемый файл (проверить на Astra с включённой ЗПС);
- состав: Maven; встроенный Jetty/Javalin (Takes — запасной, в нём уже есть опыт); серверный HTML (шаблоны JTE или Thymeleaf) и htmx; JDBC + Flyway 9; Apache POI; OpenPDF или PDFBox для печати по координатам, JasperReports 6 — для конструктора шаблонов других типографий после MVP.

Почему: это единственный кандидат, у которого все обязательные требования закрываются компонентами с обновлениями безопасности; лучшие библиотеки для `.xls`/`.xlsx` и печатных шаблонов; сертифицированный отечественный рантайм снимает вопросы в вузах с требованиями импортозамещения; команда уже пишет на Java.

Цена:

- размер поставки и память (ожидается 150–250 МБ) больше, чем у Go;
- «потолок» Java 11: новые ветки части библиотек требуют Java 17 (Flyway 10, JasperReports 7), поэтому их версии фиксируются. Если прототип покажет, что рантайм 17 x86 работает на Windows 7, базой станет Java 17.

Запасной вариант — **Go** на форке `go-legacy-win7`: если Java не уложится в память и время запуска на Windows 7 x86. Главные риски Go — один поддерживающий форк и слабое чтение `.xls`.

## Как проверяем

Один и тот же прототип на Java (и при сомнениях — на Go): HTTP-сервер со страницей, запись и чтение SQLite, чтение `.xls` и `.xlsx` в макете «Деканата», PDF с полем в заданных миллиметрах и кириллическим шрифтом PT Astra Serif, печать тестового листа.

Виртуальные машины: Windows 7 SP1 32 бит с 2 ГБ памяти, Astra Linux 1.7 с ЗПС и без, Windows 11. На Mac разработчика есть OrbStack: он даёт Linux-контейнеры и машины (в том числе x86_64 через Rosetta) — годится для сборки и проверки на образе Astra без ЗПС. Windows 7 x86 и Astra с ЗПС в OrbStack не запускаются — нужны UTM/QEMU или VirtualBox на отдельном ПК.

Критерии: запуск без установки чего-либо, старт быстрее 5 секунд, память меньше 300 МБ, отклонение поля на отпечатке не больше 0,5 мм.
