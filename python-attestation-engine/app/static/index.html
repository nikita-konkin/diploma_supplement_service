Отчёт по аттестации кафедры

Сервис выгружает из РИТМ «Аттестацию по выбранной группе» по группам кафедры и «Процент аттестаций по кафедрам», затем собирает краткий и подробный отчёты.

Группы кафедры

Отметьте направления своей кафедры. Выбор запомнится для кафедры, новые группы тех же направлений попадут в отчёт сами.

Как защищены данные Вход — учётной записью РИТМ: пароль проверяет портал, сервис хранит только сеанс портала в памяти и забывает его при выходе или через 30 минут бездействия. Выгрузка идёт под вашей учётной записью, поэтому в отчёт попадает только то, что портал показывает вам. Выгруженные данные содержат ФИО и баллы студентов, поэтому готовые файлы удаляются с сервера через 30 минут.
