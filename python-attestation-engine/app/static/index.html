🔒 Как защищены данные Страница открывается только после входа на сайт. Логин и пароль РИТМ передаются по HTTPS и используются для входа в портал на время одной выгрузки. Без галочки «Запомнить» пароль не записывается ни на диск, ни в журналы. С галочкой хранится зашифрованным (AES-256-GCM), ключ шифрования выводится из пароля входа на сайт и не хранится на сервере. Выгруженные данные содержат ФИО и баллы студентов, поэтому готовые файлы удаляются с сервера через 30 минут.
